# 当前架构

浏览器（React/TypeScript/ECharts）通过受控本机HTTP连接 Python/FastAPI 服务。`browserHost`读取可信启动描述；基础`ApiClient`核对协议、配置和实例，指数/量额Client负责各自契约。页面不能直接读取SQLite或业务文件，浏览器不负责采集调度。

服务装配为HTTP边界 → 更新协调／公开MarketData门面 → 指数、量额及预算实现。保留父写锁、只读事务、快照成员校验、来源校验、原子发布与操作身份。`update_service`服务当前参数化指数和量额启动/周期流程，不承载退役操作。

## 原子发布与恢复

价格使用v2数据库、不可变原件与快照；量额独立根保留原件、计算输入、观察及发布回执。读路径不自动恢复、不建目录、不采集；只有显式获准写流程处理发布和恢复。固定版本能重放，失败不得替换上一成功版本；无法证明归属时保留未知。

## 协议与运行边界

OpenAPI 2.0.0是唯一HTTP结构来源；安装包资源和浏览器校验器由同一源生成。保留health、基础session、index-series、market-activity和overview路由；旧API无处理器、不回退旧库。新基础配置与范围身份防止旧连接混用，v2存储本身不迁移。

托管启动器生成一次运行的描述文件，管理自己的服务和Vite进程。服务退出、父管道断开或身份变化都必须停止相应连接；不会接管已运行的其他实例。周期调度仅在服务存活期间运行，不建立系统任务。

旧实现及未验收增量本地保全，干净master采用无旧父提交的新基线。上线与日常环境切换另行授权。
