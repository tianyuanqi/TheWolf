# TheWolf 业务约束

本文件承接2026-10-23从协作规则移出的业务边界，不增加产品范围或实施授权。当前只做个人使用的服务端和浏览器端，桌面客户端、手机app不在短期范围；数据层不依赖界面，分析层不依赖模型，AI不提供金融事实。

需求和验收见[PRD](PRD-V0.1.md)，字段与时间模型见[Data Model](Data-Model-V0.1.md)，来源及风险见[Data Sources](Data-Sources-V0.1.md)，模块和运行边界见[Architecture](Architecture-V0.1.md)。这些设计中的未确认或未实现内容不自动成为本轮任务。

### 1. 时间正确性

历史研究区分数据所属期间、发布时间、获取时间与修订版本。不能使用未来披露信息、当前行业成员或后来修订数据冒充当时可知信息。历史版本不足明确标注，不静默替换。时间版本与原子发布等基础约束从第一条数据开始落实，不能因“小切片”延期。

### 2. 金融口径

金额、成交量、换手率、复权、估值和行业分类保留单位、定义、来源及版本。切换来源前验证口径兼容性；缺失不等于零，成交额不等于资金净流入。业务、行业分类与市场概念分开。

### 3. 关键结论与证据

事实性结论关联具体资料版本和页码、段落或表格；计算关联输入快照、公式和参数。引用存在不代表结论正确，必须验证支持关系。明确区分事实、计算、推断与未知；不输出黑盒 BUY/SELL 或自动荐股结论。

### 4. AI 边界

AI 通过受控工具获取数据和分析结果，不以模型记忆补金融事实；外部文档不具有指令权限。无模型连接时，本地数据查询、资料阅读与确定性分析仍可用。

### 5. 数据保留与恢复

更正追加版本，不覆盖旧研究依据。自动清理不删除被报告引用的原件、固定计算输入和用户笔记。代码回滚、数据恢复和研究重放分别验证。

### 6. 本地产品与约束解释

- “可信服务端”指本地 Python 服务及受控工具接口，不要求云服务器、账号或多用户体系。
- “窄屏”指桌面窗口缩放及最小支持窗口尺寸，不自动增加手机适配。
- 150 GB 是用户明确的本地金融数据软上限；设计稿中的性能目标、历史起点、样本量、观察天数及排期是建议，确认前不能作为已承诺数值。
- 产品需求与首批范围归 PRD，长期范围归 Implementation Plan，近期目标与依赖归 Roadmap-Tree，授权与任务详情归 status；不要从旧全量设计或历史任务目录自动启动实施。
- 首个“小批真实日线 + 官方公告 → 本地保存 → 页面查看 → 点击证据 → 中断恢复”切片的实际范围与验收保留在原任务和报告中；它证明基础路径，不等于市场看板或论点闭环产品价值已经验证。
- 既有设计中的后续模块/schema 是方向和契约，按当前阶段需要细化，不要求先把未来平台全部建完；修订概念模型不等于批准数据库迁移。

## 单位、版本与发布的实现约束

以下合并自原编码规范§6—8、§11—12、§26；不改变既有口径。

- 元/万元、股/手、小数/百分数、时区、复权方式及股本范围必须可查；单位转换集中在明确边界。按实际契约选择Decimal、整数缩放或浮点数，明确精度、舍入、缺值、零分母、越界和非有限值处理，不强制所有计算用同一数值类型。
- 原始资料、标准化事实、派生计算和分析结果分开；原件和已发布版本不原地覆盖。清洗、更正及重新解析保留新旧版本，计算关联固定输入、算法与参数；临时响应按已确认保存策略处理，不一概永久保存。
- 缺失、异常与真实零值可区分；历史查询、筛选和计算先选当时可知版本。来源不具备历史版本时明确限制，不能以最新值替代，也不能由模型字段存在推断来源数据存在。
- 相同输入版本重复导入不产生重复事实或发布，不能为去重丢弃合法修订。数据库与文件共同写入须保证查询不见半成品、中断可恢复、重试不破坏旧版、旧引用仍可解析；具体协议见[架构§12](Architecture-V0.1.md#原子发布与恢复)。
- 网络获取与本地读取分开，断网仍可读取已保存资料；前端负责交互，可信本地服务执行金融规则。界面不直接读取业务SQLite或原件路径，文件请求由后端核对标识和快照成员；领域层不依赖界面、HTTP框架或具体数据库。
- 只读路径不隐式建库、建目录、加写锁、恢复或采集；恢复写与显式更新分别声明。旧库兼容与已知例外以实际任务、契约和验证范围为准，不把目标写成已实现。

## HTTP契约与架构边界

[contracts/openapi.yaml](../contracts/openapi.yaml)是HTTP结构的唯一可编辑来源；请求、响应、错误和协议头不在其他文档另建权威。生成内容不手改，兼容影响须核对实际调用者；结构校验不能代替金融和时间语义。职责及理由见[正式ADR](Architecture-V0.1.md)，当前实现范围见[status](status.md)。旧阶段计划不自动启动实施或恢复桌面要求。
