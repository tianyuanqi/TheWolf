# 当前数据与版本

当前模型分别保留来源原件、规范化价格／量额、固定快照、计算和操作回执。金融数值采用契约规定的十进制字符串与精度；缺失原因、真实零、撤回及不支持不能混同。交易日期、采集开始/完成、发布时间和快照版本分别保存；当前历史回溯资料不等于历史当时可知。

价格按canonical指数身份和固定三年窗口组织，指数根中的v2发布与原件由数据层管理。量额使用独立根，指数量额绑定固定价格版本；市场合计按明确锚定日和日历读取，不能拼接不同版本。计算明确公式版本及输入标识，旧公式和旧版本不原地改写。

HTTP字段以[OpenAPI](../contracts/openapi.yaml)为准；发布、回放和恢复见[架构](Architecture-V0.1.md)，来源和精度见[来源口径](Data-Sources-V0.1.md)。退役旧代码不删除或迁移旧数据文件。
