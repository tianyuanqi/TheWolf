# 行情总览需求

## 1. 产品目标

为个人中长线研究提供可追溯的本地市场观察。服务负责事实与确定性计算，浏览器负责展示；不接入产品内AI，不输出交易建议。

## 2. 当前交付范围

本基线收录已验收的行情总览：上证指数、深证成指、创业板指、科创50，沪深北三市成交额（保留沪深两市后端基础）；日、周、月K线，八档可选均线（5、10、20、30、60、120、200、250），区间观察、量额、数据来源与版本说明、明暗主题、桌面窄窗口。默认均线5、10、20、30、250；价格显示两位，官方原精度参与计算。

保留显式手动更新、启动观察、受预算限制的周期更新、断连重接和操作记录保护。金融写权限、输入绑定、预算和发布校验由本地服务执行。显示既有资料与采集新资料分别处理。

## 3. 可观察结果与边界

选中指数或市场后，表格、图表、观察窗口及来源说明对应同一固定版本；缺数、失败、撤回明确显示，不能填零。同连接读取失败保留旧结果并提示；更换数据范围不能继续冒充原根结果。未知请求不自动重发。

用户已验收行情总览及北交所扩展，本次仓库整理不扩大验收范围。大资金动向、标的查询尚未验收，不在本基线。旧沪深300、002245专用切片与原生客户端已退役；通用指数登记中的沪深300标识不等于恢复旧切片。

## 4. 后续范围

后续功能先建立任务和验收标准，再独立开发。本基线不附带未来模块的实现或数据迁移授权。
