# 本地数据保存范围：A 股大盘与个股

日期：2026-09-22。状态：设计建议，待用户确认；本次仅定义保存范围，不启动采集、定时任务或业务实现。依据：[PRD](PRD-V0.1.md)、[数据模型](Data-Model-V0.1.md)、[架构](Architecture-V0.1.md)。当前授权与进展见 [status](status.md)。

## 1. 保存原则与范围层级

围绕“日常观察全市场、长期深入研究少数公司、结论可回到证据”组织数据：全市场轻量结构化底座 + 全市场公告索引 + 重点公司深度档案 + 可重建分析缓存。大盘与个股共享同一份证券和日线底表，不各存一套。

本文的“本地缓存”包含三种不同生命周期：

- 长期事实库：标准化行情、主数据及其更正版本、公告索引，不能按普通缓存 TTL 到期删除。
- 研究档案：官方原件、被引用解析版本、证据、笔记、报告和固定计算输入，受引用保护。
- 可重建缓存：聚合、技术指标、图表序列和搜索索引，可按空间回收；计算结果一旦成为报告证据，需保留该证据结果及重放依赖。

“核心”表示建议完整 V0.1 应具备的能力，不表示首个真实切片必须全做，也不表示现已获实施授权。来源权限、字段可得性及历史版本能力仍待验证。

## 2. A 股大盘

| 数据集 | 本地保存内容 | 支持的需求 | 范围与优先级 |
|---|---|---|---|
| 证券全集与身份历史 | 公司/证券 ID、交易所、板块、代码与名称变更、上市退市日期、证券类型；按日期的全集快照 | 正确界定沪深京普通 A 股，避免遗漏退市样本或混入基金/B 股等 | 核心，全市场；历史不足标明边界 |
| 交易日历与证券状态 | 各交易所交易日/时段、休市变更、停复牌、ST 等状态及生效区间 | 区分停牌、未上市、退市与数据缺失 | 核心，全市场 |
| 全市场个股日线底表 | 未复权 OHLC、可比昨收、成交量、成交额、交易范围、币种和原始单位 | 市场与交易所成交额、涨跌家数；向个股钻取 | 核心，全市场；不能只保存指数或市场合计 |
| 复权与公司行为 | 因子、方法/锚点/版本；可得分红、送转、配股等事件及公告/登记/除权/支付日期、实施状态 | 个股趋势和价格窗口比较，核验除权影响 | 核心底座，来源支持范围内接入并披露缺口 |
| 每日基础指标 | 总/流通/自由流通股本与市值、对应换手率、PE/PE-TTM/PB/股息率及定义 | 个股比较、估值历史、换手异常 | V0.1 按来源能力接入；不得因可选字段缺失伪造完整性 |
| 指数主数据和日线 | 指数身份、发布方、点位、OHLC、收益类型、成交字段（若有）及其覆盖口径 | 观察市场方向、公司与基准比较 | 核心，小白名单；候选上证综指、深证成指、创业板指、沪深300、北证50 |
| 行业体系与成员 | 一套一级行业代码/名称/定义/版本，公司归属、生效时间、公开时间和成员快照 | 行业成交分布与集中度 | 核心，先当前及开始采集后快照；有真实历史证据才扩展历史 |
| 市场与行业派生统计 | 全市场/分交易所/分行业成交额、行业占比、涨跌平家数、趋势与历史比较；样本分母、缺口和计算版本 | 市场总览、历史图表 | 核心，可重建缓存；一级行业含“未分类”以便对账 |
| 官方核验资料 | 已选同口径交易所统计的原始发布、日期、覆盖范围和版本 | 检查本地汇总是否可信 | 核心核验依据，按可得性保存；口径不同保留差异说明 |
| 宏观与政策发布 | 国家统计局、央行已选栏目的索引、重要正文/原件、发布时间、修订关系 | 市场研究外部背景与引用 | V0.1 小范围官方资料；完整宏观序列与全球指标属于后续扩展 |

全市场公告索引也由共享底座保存，字段及下载规则见下一节。指数成分和权重历史仅在需要重建指数、解释贡献或按成分研究时扩展；查看官方指数日线不要求先具备全部指数成分历史。

涨跌宽度使用有效可比昨收；停牌、新股无可比昨收、缺失数据分开计数。行业统计只使用相应时点可支持的成员版本，不能用当前成员回算早年行业。全市场估值不是个股 PE 的简单平均，如未来增加该指标，需另行定义权重、亏损处理和财务时点。

## 3. 个股：全市场基础档案与重点公司深度档案

| 数据集 | 本地保存内容 | 普通公司 | 持有/重点观察/研究公司 |
|---|---|---|---|
| 身份、行情、复权、每日指标、行业 | 使用第 2 节共享底表，保存来源与版本 | 长期保存 | 同一底表，可按已授权范围补充更早历史 |
| 公告索引 | 公告 ID、主体、标题、类别、报告期、发布方/渠道、发布时间、URL、更正关联、首次发现时间、下载与解析状态 | 全市场增量索引；不默认下载所有 PDF | 同一索引，按公司策略归档原件 |
| 定期报告 | 年报、半年报、季报、摘要与更正版本；PDF/HTML 原件、正文和页码/表格定位 | 用户打开或指定研究时按需归档 | 优先完整年报和最新中期/季度资料；摘要不代替所需原件 |
| 重大事件与风险公告 | 分红、回购、增减持、融资/重组、业绩预告/快报、减值、诉讼处罚、担保质押、问询及回复等原件 | 索引默认保存，原件按需 | 根据研究范围归档，类别规则透明；更正保留旧版 |
| 正式 IR 与业务资料 | 正式投资者关系记录、公司官网/IR 的相关资料及版本 | 按需 | 按研究问题归档；公司自述保留其性质 |
| 业务与证据卡 | 主营、产品、客户/订单、收入构成、技术储备/产品/验证/订单/收入阶段、未知和冲突；逐项关联报告期与原文证据 | 不自动批量生成全市场画像 | V0.1 检索及人工/辅助保存；不能用概念标签证明收入 |
| 财务事实与收入分部 | 三表关键值、单季/累计/年度口径、合并范围、单位、重述链；收入按产品/地区/行业各自分组 | 不要求 V0.1 全市场结构化 | V0.1 可保存带证据的必要数值；系统化抽取与比较属 V0.2 |
| 描述性分析 | 均线、区间涨跌/回撤、高低位置、成交相对强度、换手及估值历史分位 | 按查询生成，可回收 | 常用查询可预计算；保存窗口、样本量与输入快照 |
| 用户研究档案 | 关注标签、项目问题/状态、笔记、证据关系、报告、固定计算和引用 | 用户创建后保存 | 长期保存；暂停项目或取消关注不删除既有资料 |

财务结构化后续建议覆盖收入、归母及扣非利润、经营现金流、资本开支、现金、负债/有息负债、净资产、EPS、ROE、分红等，再按银行等公司类型补专属字段。不同公司类型不强塞同一评价模型；自由现金流、增长率、利润率等派生值记录公式与输入，不伪装成直接披露事实。

归档触发应与项目策略分开记录：新建研究项目按展示的资料清单回填；关注标签按配置启用增量；暂停项目关闭该项目自动深度归档，不影响其他仍有效策略或同公司其他活动项目。归档失败单独显示实际完成等级，不能把索引存在等同于离线原件可读。

## 4. 历史深度与更新方式

历史起点和回填窗口仍待用户确认，既有建议统一见 [PRD §4.3、§5](PRD-V0.1.md)，本文件不另设一套数值。结构化历史在确认范围内一次回填、以后增量积累，不滚动删除旧年度；新上市证券从实际上市日起，退市证券保留已有历史。旧档案缺失不承诺可以补齐。

| 类型 | 建议更新触发 | 发布与失败处理 |
|---|---|---|
| 日历、主数据、状态、行业 | 启动追补、日检查及变更事件 | 验证生效区间与证券映射；行业无历史不反推 |
| 日线、每日指标、指数、因子 | 完整交易日数据可用后增量，重叠回看捕捉更正 | 来源字段可有不同到达时间；各自标注完整性，保留上一可用快照 |
| 公告索引、重点公司与官方栏目 | 每日增量含周末、启动追补；按来源限制调频 | 全页遍历、去重、重叠查询；原件/解析可独立重试 |
| 财务与公司行为 | 新披露、实施及更正事件 | 状态/数值追加版本，不覆盖旧依据 |
| 派生指标和索引 | 输入版本、成员或算法变化；查询触发 | 新键重算最新视图，固定报告依赖继续保留 |

本次不启用调度。具体调度时间是后续运行配置，不保证收盘后某个固定时刻数据一定完整。应用关闭或电脑休眠时的追补沿用现有架构设计。

## 5. 每类数据共同需要保存的上下文

字段定义以 [数据模型 §§1–2](Data-Model-V0.1.md) 为准，至少能回答：数据属于哪天/哪个报告期、何时生效、该版本何时公开、何时获取/首次发现、来自哪里、采用什么单位和口径、替代哪个版本、历史可知性有何证据。

所有数据集保存版本、批次、质量状态和缺失原因；原件保存内容哈希，计算保存输入快照、公式/参数/代码版本。只有当前修订值时明确标记，不能因记录了历史交易日就声称拥有当时可知版本。

派生缓存键包括证券/全集、日期窗口、信息截止时刻、PIT 模式、输入快照、来源策略、复权方法/锚点、行业成员版本以及计算参数/算法版本中适用的项。不能只以“股票代码 + 日期”缓存所有研究结果。

## 6. 空间、清理与暂不纳入的数据

遵守用户明确的 150 GB 本地金融数据软上限；分类预算及容量估算统一见 [数据模型 §8](Data-Model-V0.1.md)。不将未实测体积写成可容纳公司数量或历史长度承诺。

优先回收无引用的派生缓存、可重建搜索索引、过期日志/诊断响应和确认无任务依赖的失败暂存。重复文件按内容哈希去重但保留来源关系。普通未引用原件是否可降级依档案策略，不对重点或固定资料自动删除。临近上限先暂停非必要下载；受保护资料增加到超预算时提示调整范围或存储，不破坏引用。

不默认缓存分钟/Tick、逐笔成交、盘口/Level-2、全市场所有公告附件、新闻/社交流、券商研报全集、全部概念板块历史、全市场完整财务附注结构化、完整海外证券库。融资融券、龙虎榜、股东户数等不在本轮核心清单，后续有明确研究问题和来源口径后按需扩展。

复权图表由原始日线和独立因子生成，不永久保存三套完整日线。市场/行业汇总由共享底表计算，不另抓一套无法追溯明细的数字充当唯一事实源。各来源“资金流”指标不作为成交额的别名。

## 7. 可验证条件与实施顺序

- 同一快照可以从个股明细复算市场、交易所和行业成交额，并解释未分类、停牌和缺口。
- 断网后可读取已保存日线及已完成归档的公司原件；仅有索引的资料明确显示未下载。
- 新财报/更正/因子版本进入后，固定旧研究输入和引用保持不变；无历史证据的查询返回限制。
- 清理可重建缓存后分析能够再生；研究原件、引用定位及计算重放依赖仍完整。
- 同步中断后仅显示已完整发布批次，恢复重试不重复计数；旧完整快照可继续读取。

实施仍按既有首个真实流程切片：小批真实日线 + 一份官方公司公告 → 本地保存 → 页面与证据查看 → 中断恢复。该切片验证基础机制后，再依次扩展全市场结构化底座、全市场公告索引、重点公司深度归档和后续财务/宏观结构化。
