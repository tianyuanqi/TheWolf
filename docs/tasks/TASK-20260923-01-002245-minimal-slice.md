2. 来源最小验证：核验证券映射、日历、字段与权限，试取少量日线和一份官方 PDF；记录来源和真实可用性。确定来源及冻结窗口，形成可追溯契约；失败按升级规则返回证据。
3. 实现最小获取/验证/不可变保存/发布/查询链路及相应自动化测试。先让真实样本能从本地 API 读出，再补齐冻结 60 日窗口，保留公告原件。
4. 完成访问保护与原件定位，按确认后的局部 UI 做单页联调；实际浏览器核验状态、页码和缩窗。
5. 在隔离根执行重复同步、修订、断网、逐阶段强制中断、写失败和损坏恢复；核验旧快照稳定。检查 Tauri 开发启动/退出/重启及消费者；不打包分发。
6. 独立审查与修复、用户演示准备；交付证据并更新唯一状态源。

## 7. 自主处理与升级条件

常规模块拆分、接口命名、测试夹具、必要依赖、小范围修复及按 §4 验证合格的免费来源选择自主处理。业务含义、免费方案不能满足后的替代取舍、扩大日期/证券/公告数、付费权限、已有数据迁移和重要架构变化需返回相应决定者。

来源授权拒绝或条款不明不自动重试绕过；瞬时错误按来源限制有限重试并记录上限。同一关键实现问题两次有假设、有验证的修复仍失败，按执行评估升级；不无限修改直到测试变绿。来源能力未验证及 UI 未确认部分分别记录，不将已确认的免费选源原则继续列为用户待决项；不阻断独立工作。
