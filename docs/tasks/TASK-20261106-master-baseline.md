# MASTER-BASE 任务约定

所属1.1—1.3／工3，保护工1、工2及2.1。目标：保全旧历史和未验收改动，移除分离前旧专用实现，形成只含已验收行情总览的本地master，审查和测试附件不纳入。

用户已授权本地整理、清理、回归和提交；推送GitHub、切换默认分支、删除旧分支前再确认。本轮明确不做方案独审。基线提交形成后、推送前仅安排一次独立代码审查：大文件／密钥／真实数据检查、总览共用依赖、干净克隆、旧功能移除；其余不单独派发。

完成标准：旧历史和未验收工作可恢复；总览共享连接、更新、预算、只读安全和计算保留；旧专用页面／API／原生宿主移除；新树不含未验收业务、来源原件、真实数据、配置秘密、截图日志和报告包；在隔离合成数据上通过必要回归与构建，测试资源恢复可核验；固定本地提交按限定范围独审。

重大架构／公共接口整理，依本轮用户明确指令限定审查，不能称为全范围L3审查。所有附件仅在本地保全。金融数据、真实采集、日常运行配置与部署不在本轮操作范围。
