# 第一批市场与指标看板设计建议 V0.1

制定：2026-10-04。依据 [PRD §5](PRD-V0.1.md#5-v01-范围契约) 与用户“开始下一步”。本文细化数据含义、页面与验收，供确认；**不是开发任务书；§5.5及§5.6中的首版日期边界已获用户确认，§5.6其余实施设计供本次任务书审阅，其余未单独确认的建议不表示获批，全部新功能均不表示已经实现**。授权与未决问题统一见 [status](status.md)。初次设计准备仅查公开页面/文档并制作隔离的布局预览，没有调用项目采集器、回填历史或修改数据库。

## 1. 本轮结论与建议

第一批看板可以形成一套完整的收盘后观察流程：先看市场表现，再分别查看价格位置、估值、交易活跃度、资金成本与融资增长。它们共同辅助判断，不合成“现在该买/卖”的分数。

建议采用以下默认方案，等待用户确认；已确认的 A 股/港股范围、七组指标及长期保留原则不重开讨论：

| 待定事项 | 推荐方案 | 理由及代价 |
|---|---|---|
| 科创板/北交所代表 | 科创50（000688）、北证50（899050） | 清楚表达代表性样本；不冒称覆盖板块每家公司。北证50只有自2022年起的历史，不可能补齐更早不存在的五年。科创综指覆盖更广，但000680为全收益口径；若希望全板块价格表现，应另比较000681，不能静默替换 |
| 人民币黄金与白银 | 上海金 SHAU 午盘基准价、上海银 SHAG 午盘基准价 | 每日一个有明确名称的人民币参考价格；金为元/克、银为元/千克。适合观察环境，不能当作日收盘K线或沪金/沪银主连 |
| 布伦特 | EIA Europe Brent Spot Price FOB，美元/桶 | 适合外部成本环境观察，有官方长历史页面；这是现货参考价，更新可能晚于交易日，不等于ICE近月期货行情 |
| 铜 | COMEX HG结算价的可追溯连续序列；优先评估CME近月方案 HGCP1 | 名称、合约与换月关系清楚。官方产品存在许可要求；先验证合格免费来源能否提供对应数据，不在未验证前承诺可接入，也不把不明“铜主连”当作同一序列 |
| 美元/人民币 | 在岸 USD/CNY 16:30收盘价 | 更直接反映该时点市场汇率。不能用中间价或整点参考汇率冒充；免费历史不足时再讨论是否单列中间价，不自动替换 |
| 更新 | 第一版手动“检查更新”；启动仅读本地 | 沿用用户可控的使用方式；逐来源显示结果，自动日程与休眠追补后续再决定 |
| 页面 | “分区总览”默认；另提供“指数表优先”布局预览作比较 | 首页先看指数/涨跌/成交，复杂指标进入对应板块；不把七组指标塞进一个大屏 |

这些建议中的来源事实及本轮访问限制见 [Data Sources §7](Data-Sources-V0.1.md#7-首批看板设计的公开资料核验2026-10-04)。不能从界面预览推定接口或历史能力已经可用。

### 2.3 数据能力检查的优先次序

先解决会影响整批交付的难点，再投入完整页面实现：

1. **估值历史**：逐指数查PE-TTM/PB/股息率方法、实际起点、日度覆盖及获取条件。近期中证接口不够支撑五年分位；月度资料也不能插值成五年日度历史。
2. **COMEX连续数据**：查免费来源的合约身份、结算字段、历史规则和获取条件。官方连续产品不是已验证免费接口；不绕过访问限制，也不自动采购。
3. **市场统计**：验证沪深京统计边界、涨跌停规则、港股成交范围及二十日基准输入；指数成交额不能代替全市场成交额。
4. **其他日度与月度序列**：按来源逐一验证历史、更新延迟、节假日、修订与可重放边界。

本轮只完成公开资料核验。后续验证建议先取少量代表日/月份和一次换月边界，保存到隔离证据目录；只有基础映射通过后才检查完整五年窗口。具体请求量、截止日期和文件限额在验证范围明确后确定，本文件不自动启动下载。

有缺口时形成明确的“序列—字段—期间—原因—可行替代”。采用带来源的人工导入也必须通过同一口径检查；免费路径不够才提交收费或范围取舍。显示缺失是正确失败行为，**不是该项核心能力验收通过**。

## 3. 指标计算与解释建议

沿用数据模型的时间/单位约束。下表补充候选计算细则，确认后再固定公式版本；合成例子仅用于验收，不是市场数据。

| 指标 | 建议计算/展示 | 能回答与不能回答 |
|---|---|---|
| 20/60/250日涨跌 | `P(t)/P(t-N)-1`；N个完整交易日间隔，需要N+1个有效点。不得用20个自然日代替20个交易日 | 比较近期表现；不说明估值便宜。个股使用明确复权序列，指数使用统一收益类型 |
| 距窗口高点跌幅 | `1-P(t)/max(P(s))`，窗口由用户选择，显示“距最高收盘价低X%” | 表示当前价格位置；不是期间最大回撤，不是上涨空间 |
| 上涨占比 | 上涨/(上涨+下跌+平盘)；同时展示三类家数与排除数，分母0时不适用 | 看上涨覆盖面；不代表资金流入或未来上涨概率 |
| 收盘涨跌停 | 来源可信汇总或按当日限制价/价格精度核验；非固定10%阈值 | 看极端收盘分布；不与盘中触板数混用、不对港股套用A股规则 |
| 成交相对强度 | 当日同范围成交额 / 之前20个预期开市日成交额均值，排除当日；窗口有未知缺数不擅自向前跳过补齐 | 看相对活跃度；不能直接解释成流动性资金总量或净流入 |
| 五年估值分位 | 建议用观察时点向前五个日历年的有效日度样本，含观察日；`(小于当前值的样本数+0.5×等于当前值的样本数)/有效样本数` | 看相同定义下的历史位置；不是跨指数价值排名或胜率。负PE/不适用值排除并披露原因；PB适用性单独判断 |
| 盈利收益率差 | `1/PE_TTM - 中国10年国债收益率`，显示百分点及两条原始收益率 | 比较盈利与债券收益率尺度；不是预测回报或严格风险溢价估计 |
| 股息比较 | `股息率TTM - 国债收益率`；可切换二者比值（倍）。固定指数股息方法，债券分母≤0时不展示有投资含义的倍数 | 观察现金分红相对利率；不保证未来分红、不把股息当无风险收益 |
| 资金成本 | DR007与7天逆回购利率同图；可显示差值bp；HIBOR一个月另图 | 看银行间短钱成本，A/H分别解读；不证明股市一定上涨 |
| 融资与货币增长 | 社融存量同比与M2同比同月同图；差值为前者减后者，单位百分点 | 看两类增长的相对变化；不代表股市“剩余流动性”金额 |

默认保留原序列，差值/比值不能算成第二份独立证据。PE选择计算用股本或其他方法后，整段历史必须兼容；不能用当前成分股重建旧估值。五年覆盖不足、有效样本或质量不达已约定条件时不展示“完整五年分位”；可另显示明确命名的实际可用窗口，但不替代五年目标。北证50等序列本身不足五年是客观例外，应显示其基日、回溯与正式发布段。

涨跌区间的起止点按所选市场交易日历定位，缺少目标日数据时不能以更早的有效点替代。五年窗口应逐日列出有效值、不适用与未知缺数；建议完整交付不留未解释缺口，不能以“已解释为缺失”冒充已取得完整估值。允许怎样的残余缺口及有效样本下限，须结合真实来源结果明确，不能预先以任意覆盖率自动放行。

建议股债比较先覆盖上证50、沪深300、中证500、中证1000，其他A股指数在方法核实后可用；这是计算适用顺序，不删除其价格/估值需求。港股继续提供价格与可得的同口径估值；港股股债利差待另定币种/债券基准，本批不默认套人民币国债。

## 4. 时间对齐与更新行为

### 4.1 首页日期

建议首页显示“最近已保存的完整数据”，各卡片分别标数据所属日/统计月、最近检查时间和异常状态。用户收盘后打开时，A股可能已结束、港股尚未结束、美国新交易日尚未结束；不要求它们都挂同一个“今日”日期。

选定历史查看日D时，必须区分两种含义：历史走势允许明确标注的最新修订数据；“当时可知”研究只能使用在相应截止时刻已公开/已观测的版本。首批默认属于历史描述视图，不把五年回填伪装成当时决策快照。实际切片目前不含上海时区当日，改变这一行为须在将来的实施约定中单列。

### 4.2 组合图

- 同单位利率/同比可共用纵轴；价格与估值优先上下对齐小图，避免双轴视觉误导。允许切换到双轴时清晰标两个单位。
- 不同币种价格先分别展示；可选“起点=100”只比较各自本币价格变化，不能称为人民币投资收益。
- 同日算术（如股债差）只用具有相同数据日且已可用的输入；没有交集时保留最新有效共同日并明确其日期，不把旧债息伪装当天值。
- 月度社融/M2按统计月对齐，提示发布日期；若与日度价格对照，可展示从实际公开时刻起生效的阶梯参考线，但不改变底层月度观测、不向发布日前回填。
- 缺数呈断点，不用零、不以直线连接掩盖缺口；政策利率在有依据的有效区间保持值，区别于缺失填充。
- 期货换月日标记，价格连续变化不解释为可直接赚取的持仓收益；尚无可靠连续规则时不绘制看似完整的长期铜价线。

### 4.3 更新过程

建议首版仅手动检查已选范围。界面逐来源显示检查中/新增数据/证据修订/无变化/未就绪/失败；部分失败不阻止其他独立序列发布合格版本，但跨序列计算固定输入日期与版本，不混出不存在的共同快照。

更新前后都能读上一有效数据；取消或失败不删除旧历史。显示“已保存数据日期”和“最近成功检查时间”两个值。首次没有任何数据时引导检查数据，而非显示全零行情。联网检查不自动建立全市场个股长期仓库。

### 5.3 布局与视觉建议

“分区总览”用紧凑卡片和清晰分组；“指数表优先”让十二条指数的多列数据更易横向比较，代价是新用户阅读密度较高。本窗口的可切换预览用于选择布局；数值全部是虚构示例，未接入行情，不是生产页面。

视觉沿用现有桌面深蓝与清晰证据提示的方向，可随宿主明暗主题适配；系统中文字体，正文建议14px、辅助文字不小于12px，数值等宽。间距以8px倍数组织；主操作统一，错误、缺数和过期使用文字+图形状态，涨跌不能只靠红绿区分。预览采用红涨绿跌并保留正负号；正式颜色对比度和共享组件消费者在UI实施时实测。

建议按1280/1024宽桌面及800宽窄窗口审查，实际最小支持窗口尚未获批。窄窗口收起侧栏、卡片减少列数、详情改到下方；表格必要时局部横向滚动，不让整个页面溢出。预览额外兼容会话窄宽，不新增手机版需求。

#### 日期、字段与来源

- 新指数日历按首轮报告已经读取的2025上交所年度通知和2026沪深通知建立版本，明确2025未另取深交所原通知；依据原件与哈希须可核对。冻结在2026-10-05的验收样例应为2025-09-04—2026-09-30共260日。2027规则未验证时停止新增采集，已有离线数据可读；不为M01补2021/2023日历。

## 6. 验收建议与可复查例子

以下是设计验收建议，不是已执行结果或新开发任务编号。整体交付应覆盖七组指标与已确认公共序列；技术验证失败不能自动降为“只交容易的数据”。

| 场景 | 前置/操作 | 可观察结果与方法 |
|---|---|---|
| 指数映射 | 对所有选定指数读取已保存样本，点开来源 | 名称/代码/收益类型一致；官方代表日核对，不将ETF或股票混入 |
| 五年价格与估值 | 对具有足够存续历史的每个序列选择五年 | 对全部预期日历检查覆盖、单位/修订/异常；价格通过不代替估值通过。新序列显示实际起点与回溯段 |
| 窗口计算 | 合成序列起点100、20个间隔后110；不足21点再算 | 分别得到10%与历史不足；不悄悄改用自然日/缩短窗口 |
| 当前距高点 | 窗口最高收盘120，当前90 | 显示距最高收盘低25%，不标“最大回撤25%”；改变窗口会重新固定输入 |
| 分布统计 | 合成1000只：600涨、300跌、50平、50排除 | 有效分母950，上涨占比约63.16%；排除数另列，涨停不重复加进总数 |
| 成交强度 | 之前20日均额100，当日150，保持单位一致 | 显示1.5倍；改变当日值不改变前20日均额；窗口缺一日未知值则提示缺数 |
| 分位 | 有效样本10、20、20、30，当前20 | 建议算法结果50%；显示4样本仅为夹具，不能称五年历史。另测负PE、全缺失与重复日期 |
| 股债算术 | PE=20、股息率3%、国债2% | 盈利收益率5%，差3个百分点；股息差1个百分点、比值1.5倍。PE≤0或比值分母≤0显示不适用 |
| 月度差与发布 | 社融同比8%、M2同比7%，且第二份数据晚发布 | 同月差1个百分点；发布前不可用于当时可知视角，不拿不同月份直接相减 |
| 跨日组合 | A股有D日数据，债息仅D-1；美国D日尚未结束 | 各序列实际日期可见；算术使用有效共同日；不以D标签掩盖旧值 |
| 换月与定价 | 铜换月日、金银午盘缺值各一个边界样本 | 底层合约可定位，换月有标记；不把近月跳变当成现货变化、不补早盘冒充午盘 |
| 数据失败与恢复 | 隔离根下断网、取消、部分来源异常、重启 | 上一有效资料可读；无半批可见、无重复发布；重启不自动采集 |
| 取消关注 | 隔离自选证券取消后回看旧日期 | 旧历史、原件和引用仍可读；其他关注原因不被误删 |
| 布局与可理解性 | 在约定窗口宽度，用户从总览进入估值/资金面并展开解释 | 关键文字/数值/单位不重叠，键盘路径可用；用户能分清价格位置、估值和资金成本，没有误导的综合买卖结论 |

检验覆盖应逐序列列出已验证/缺失/不适用，而非用总测试数量代替。数值容差依据来源精度和公式误差确定；性能预算在指定设备、实际范围和历史样本上测量后形成，不在本轮编造响应时间承诺。
